Logic gates are basic electronic circuits that perform logical operations on binary input signals. Standard primitive gates include AND, OR, NOT, NAND, NOR, XOR, and XNOR.

  • AND Gate: Output is HIGH (1) if and only if all inputs are HIGH (1).
  • OR Gate: Output is HIGH (1) if at least one input is HIGH (1).
  • NOT Gate (Inverter): Flips the input signal (0 becomes 1, 1 becomes 0).

NAND and NOR gates are termed Universal Gates because any Boolean logic circuit (including AND, OR, NOT, XOR) can be constructed exclusively using only NAND gates or only NOR gates.

Boolean algebra provides mathematical principles to simplify logic circuits, reducing gate count and propagation delay.

  • De Morgan's Theorem 1: (A · B)' = A' + B'
  • De Morgan's Theorem 2: (A + B)' = A' · B'

1. Basic Logic Gates

Logic gates are the fundamental building blocks of digital electronic systems. They take binary inputs (0 or 1) and produce a single binary output.

  • AND Gate: Output is 1 only if all inputs are 1.
  • OR Gate: Output is 1 if at least one input is 1.
  • NOT Gate: Inverts the input signal (0 → 1, 1 → 0).

2. Universal Gates

NAND and NOR gates are called universal gates because any logic circuit or Boolean function can be implemented using exclusively NAND or NOR gates.

  • NAND Gate: Inverted AND gate (NOT AND).
  • NOR Gate: Inverted OR gate (NOT OR).
  • XOR / XNOR: Used for parity and arithmetic additions.
